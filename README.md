# Business Sales, Profit & Customer Insights Dashboard

## Project Overview

An interactive business intelligence dashboard developed using Microsoft Excel to analyze sales performance, profitability, customer contributions, and geographical sales trends.

The dashboard transforms raw business data into meaningful visual insights to support data-driven business decisions.

## Dashboard Features

### 1. Sales Analysis
- Sales performance by product category
- Monthly sales trends
- State-wise sales distribution

### 2. Profit Analysis
- Year-wise profit comparison
- Profit analysis across business categories
- Customer-level profit performance

### 3. Customer Insights
- Top 5 customers by profit
- Customer contribution analysis
- Customer performance comparison

### 4. Interactive Filters
- Category slicer
- Year slicer (2021–2024)
- Month slicer
